# 小镇进化 · C# / .NET 10 / MonoGame 3.8.6

独立重构目录。按用户最新决定使用 .NET 10 与 MonoGame **3.8.6**，通过官方 `mgdesktopgl`、`mgandroid`、`mgshared` 模板建立 Windows、Android 和共享游戏代码。旧项目和前期 WebGL 样本保留，当前工作集中在本目录。

## 打开检查

双击根目录的 **试玩Windows.cmd**。它使用项目本地已经准备好的 .NET 10，不安装依赖，不启动网页服务。Windows 原生游戏窗口中可检查：

- 左侧六种无限耐久工具；拖到目标松手使用，农田的镰刀和播种可连续划扫小格。
- 斧子伐木掉落木材与树种；挖掘工具采集旧项目采用的草土物块、土块和石料块。点击掉落物手动入库，仓库满时原物保留。
- 右侧库存拖到空地形成材料堆。同一物品可以叠堆；滚轮调整一次拖出的数量，触屏可先点产品再用加减选择数量。拖回界面取消。
- 锤子、锯子对精确数量材料合成；锤子划过木材与石料后在空地松手可做石窑。只消耗本次明确选中的来源。
- 建筑长按400毫秒后拖动，叠到配方对应部件可合成；快速拖地图平移。点击建筑可转向、拆除、加工或取回挂载材料。
- 右下图鉴：四条一页、目录与详情翻页、拖动纸页位置、发现进度。未发现配方隐藏材料与结果，实际操作成功才解锁；图鉴只查阅。
- 每块田有9个独立作物格；旱田/水田、15秒生长、田箱收集、磨坊/石窑/烘焙坊加工、堆肥与育苗种树。
- 整数层高地形、分区网格、GPU实例化，以及包含库存、掉落物、农田、加工任务和发现记录的JSON存档。

鼠标快速拖动平移，滚轮缩放，Q/E转镜头，R调整拖动中的建筑朝向，G切换网格，Ctrl+Z撤销，Ctrl+S保存。点挖掘工具可切换开垦田地、逐层挖地、土料填地。点击“设置”可保存、撤销、缩放和回到全景。F12把截图和只读状态写入 `review/windows-manual`。

触屏点击建筑后，在建筑操作面板中旋转；长按后拖动可移动或合成。画面限制为 30 帧；Windows 按显示器选择初始窗口大小，上限 1920×1200，可继续调整窗口，并启用高分屏适配及 4×MSAA。Android 保持原生画面尺寸，暂不启用会触发当前 MonoGame GLES 合成错误的离屏 MSAA。界面按显示高度缩放，并同步换算点击区域。字体使用 44px 字形源，旧图标重新从原图导出为 256px；没有新增美术设计或外部素材。检查模式点击仅更新只读状态，截图在启动及 F12 时写入，避免每次操作都进行图片回读。

Android 安装包见 `out/小镇进化-基底-Android.apk`，包含 ARM64 与 x86_64，供 Android 手机和本地模拟器使用。它是本地调试包；尚未通过实体手机性能与完整玩法验收。

## 本轮边界

已接入本地采集、库存、地面材料堆、32条首批图鉴配方、实体组合、农作与基础加工。素材直接复用旧项目采用的模型、图标和配方说明；保留24个既有设计的分块和共享模块来源。

当前仍是可试玩的迁移版本，操作细节尚需与原版继续对齐。商店交易、公告订单、运输逻辑、大田扩建、居民、物流自动化、季节和贸易尚未迁移。现有商店、手推车、船、木栈桥和运输仓可合成并展示模型，尚不提供对应经营/物流行为；肥料可制作，使用效果待设计。

新岛屿、新建筑和新道具须先 ImageGen 设定图，再建模。既有建筑应延续材料拆件组合的设计。素材与 UI 约定见 `docs/资产与界面约定.md`。

## 五层结构

| 层 | 当前实现 |
| --- | --- |
| Town.Core | 无 MonoGame 引用的地图、物品/配方/农作/加工规则、独立 ID、原子命令、20 Hz 模拟、变化事件及JSON存档 |
| Town.Game | 官方共享工程；地形、实例化模型、正交相机、拾取、输入、旧版布局 UI 及本地保存适配 |
| Town.Desktop | Windows / DesktopGL 入口 |
| Town.Android | Android 入口与平台配置；与桌面编译同一份 Town.Game 代码 |
| Town.Content | 官方 Content Builder 清单、实例化着色器、离线模型和纹理输入 |

地形按 8×8 分区，挖填只重建受影响及相邻边界分区。拾取使用从同一份glTF离线保留的三角形，与渲染坐标及生长阶段保持一致；不读取GPU缓冲。模型通过 Content Manager 缓存；同模型/材质使用共享顶点、索引和动态实例缓冲，以 `DrawInstancedPrimitives` 绘制。无变化时不重新上传实例数据；没有通用 ECS 或额外引擎框架。

## 本地工具与检查

项目本地 .NET SDK：`.tools/dotnet`。MonoGame 包缓存：`.packages`。Content Builder：`.tools/mgcb`。原有 Android SDK API 35、build-tools 35、JDK 21 和模拟器继续复用；唯一补充的 Google SDK 包是 API 36，放在 `.tools/android-sdk/platforms/android-36`，其余组件通过目录联接引用已有安装。

用户已授权本轮所需依赖下载。下载进程禁用代理，使用直连；无 oulucloud 回退。构建脚本使用 `--no-restore`，不会自行补下载依赖。工具、包、构建产物、调试签名及检查输出均在忽略范围中，不应提交到公共仓库。

`构建Windows.cmd` 可重新构建。`scripts/Build.ps1 -Platform Android` 构建 Android；`-Platform All` 构建两者。Content Builder 的 Windows 原生图片导入不支持当前中文绝对路径，因此脚本为同一目录临时建立一个 ASCII 盘符别名，构建结束后移除，不创建平行项目副本。

核心规则检查：先在 PowerShell 执行 `. ./scripts/Environment.ps1`，再执行 `& $dotnetExe run --project tests/Town.Checks/Town.Checks.csproj --no-restore`。无需第三方测试框架。

新存档为schema 2；本项目之前的schema 1基底存档自动迁移，旧文件在下一次手动保存前保留。普通 Windows 存档在本机 LocalAppData 的 `TownEvolution.MonoGame`；试玩入口使用独立检查存档，避免误改正常数据。Android 使用应用私有目录。旧浏览器/Cocos 存档不会被读取或覆盖。

不使用 Computer Use 操作用户桌面。Windows 手动交互请用户协助；用户已明确授权直接操作 Android 模拟器进行验证。本轮没有服务器部署、发布队列、账号或在线经济。
