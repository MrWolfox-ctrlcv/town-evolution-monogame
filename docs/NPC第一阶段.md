# NPC 第一阶段

从行走和指派进入《原始方案 V0.1》的居民劳动阶段。目前可指派伐木、收割、挖掘、搬运和加工，并由居民接手日常收存与重复生产。

分支 `npc-stage1`，独立工作树 `town-evolution-npc`，从主工作树 2026-11-15 未提交源码的快照起步；
主目录 `town-evolution-monogame` 没有被修改。

## 演示岛

`试玩NPC演示.cmd`（内部走 `scripts/Play-NpcDemo.ps1`，使用项目本地 .NET，不下载任何东西）。

- 24×18 平地，南侧一段两级台阶通往高台；台阶只有一条路，所以"绕行还是走台阶"可以直接看出来。
- 住宅在 (6,5)，两名居民在门前生成。
- 右下角面板显示选中居民的饱食、体力、负重、随身货物、任务和工坊岗位。
- 左键点居民选中，右键点地面移动。右键点成熟作物、树木、掉落物或材料堆，分别指派收割、伐木、拾取或搬运；居民有随身物品时，右键点仓库可以存放。
- 存档目录与正式版分开：`%LocalAppData%\TownEvolution.MonoGame.NpcDemo`。

## 正式岛试玩与美术

双击 **试玩NPC正式岛.cmd**。入口直接进入常规岛屿的村落近景，可用设置里的全景回看山脊、海岸和村落的关系。新岛有连通入海的河道、渐缓的坡脚和近岸浅水。该入口的存档在 `review/npc-town-v2/isolated-save`，地形沿用存档中的实际网格。

居民分件保存在 `assets/character/resident-v2.json`。以每格 32 单位定义体块尺寸和关节枢轴，同一套身体可套用蓝灰草帽和砖红工帽两种外观。分开的肘和膝驱动迈步、抱箱及工作动作，点选依据当前姿势与场景遮挡。

空闲居民默认自动收集附近的零散掉落物，也会从田边收获箱取货，按重量携带并步行到仓库存放。玩家堆在地上的合成材料可以右键指定搬运。仓库满时物品保留在原处或居民随身库存，腾出空间后继续存放。右下角可以单独开关每名居民的自动收存，取消任务会暂停该居民的自动指派。

回看旧版《镰刀按可见作物格收割》和《Farmland upgrades》后，继续让居民命令使用现有可见网格命中，保留作物单格和田箱容量。场景取消地块上方的收获篮和成熟数量，田箱容量在选中田地后的环形操作中查看。树木继续使用素材实验室已采用的两个叶簇，并在叶纹理缩小时用多级过滤。

## 相机操作

移动或缩放时，3D 场景临时降低内部渲染分辨率并暂停多重采样，菜单和文字仍以窗口原分辨率绘制。操作结束后恢复画质设置。滚轮向光标处平滑缩放，常规试玩仅在显式开启检查模式时生成诊断。

远景阔叶树使用从原有 7 号叶簇导出的简化模型，单棵从 15,976 个三角面降至 1,453 个。近距离静止时显示原模型。地形只绘制当前视野内的分块。

同一台 Windows 设备、同一个岛屿存档和 1920×1200 窗口，各记录 101 帧拖拽缩放样本。平均帧间隔从 43.93 ms 降至 16.73 ms，95% 分位从 50.07 ms 降至 17.14 ms。原始记录在 `review/camera-baseline` 和 `review/npc-playtest`。停稳后验证了 1920×1200 与 4×MSAA，以及居民点选、地面指派和收割入库。

## 正式岛的居民工作

- 左键选中居民，右键按目标指派。左键空地或按下中键取消选择。按住中键可移动镜头。
- 挖掘工具直接拖到目标使用。完整的空平地可开田，土坡、起伏的裸土与岩层可挖料。将库存或地上的土料拖到水面或下凹的裸土格可填高一层。松手于无效目标会收起工具。
- 建筑动作采用旧版的扇形与环形布局。按钮围绕模型，空隙留给地图。石磨、石窑等工坊仍可用原有手动加工入口。
- 居民饱食低于 40 时会走到仓库吃现有食物，体力低于 30 时回住宅附近休息。两种需求在当前指令结束后优先处理。
- 选居民后点击「指派挖掘」，再右键选格子。也可以按住 Shift 右键挖地。居民到地块边上操作，土料或石料照常掉在现场。
- 右键工坊可指派一次加工，或者在居民面板点「指派岗位」再右键工坊持续加工。石磨岗位默认磨面粉，按住 Shift 右键分配碾米。每座工坊最多有一名负责人。居民会从仓库领原料、走到工坊开工，并把成品步行送回仓库。可在居民面板解除岗位。
- 用锯子加工 3 份木材可造手推车。选中居民后右键手推车，居民会前往取用。推车载重上限 32 kg，铺路能提高推车速度。卸货后可从居民面板停放。
